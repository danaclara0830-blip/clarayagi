07
DESIGN RULES
  • 1
    Red는 하나의 목적으로만
    한 화면에서 Red가 등장하는 포인트는 1–2개. CTA 버튼 또는 헤더 블록. 둘 다 Red면 희석된다. Error state의 Red는 별도 역할.
    --er: #E62E2D · Primary action only
  • 2
    White space가 에디토리얼을 만든다
    섹션 간 여백 최소 48px. 카드 패딩 16px 이상. 빽빽하게 채우지 말고 여백으로 콘텐츠를 강조.
    section-gap: 48–64px · card-padding: 16–24px
  • 3
    Anton은 대문자로만, 작은 크기 금지
    Anton 최소 사용 크기 22px. 그 이하는 DM Mono로 대체. 절대 소문자로 쓰지 않는다.
    Anton min: 22px · ALL CAPS only
  • 4
    Border radius 일관성
    버튼·인풋 2px / 카드 3px / 헤더 블록 0px. 둥글게 만들지 않는다. 에디토리얼의 샤프함은 각진 엣지에서 온다.
    btn/input: 2px · card: 3px · header: 0px
  • 5
    텍스트 컬러 4단계만 사용
    #0D0D0D (primary) · #555 (secondary) · #999 (muted) · #CCC (hint). 이 밖의 gray는 사용하지 않는다.
    ink / ink2 / ink3 / ink4
  • 6
    아이콘은 Tabler Outline만
    filled 아이콘 사용 금지. stroke-width 1.5. 크기는 16–20px. 버튼 내 아이콘은 텍스트와 같은 색상.
    tabler-outline · 16–20px · stroke 1.5
